# Elite Scanner v2 — Optimized

Complete refactor of the original `elite_scanner_bot.py` with performance, architecture, and bug-fix improvements.

## 🚀 Key Improvements

| Priority | Fix | Impact |
|----------|-----|--------|
| **P1** | **Indicator Caching** (`IndicatorCache`) | MACD/ADX/EMA computed **once** per symbol/timeframe. Eliminates 2-3x redundant computation. |
| **P1** | **Volume Pre-filtering** | Only scans liquid USDT pairs (≥500k 24h vol). Reduces pairs from ~1500 → ~100-200. |
| **P1** | **Fixed MA200 Slope Logic** | `sma_200_prev` now correctly compares current vs previous-candle MA200 (was comparing shifted windows). |
| **P2** | **Separated Filter vs Scoring** | Hard filters (fast reject) run first; scoring only runs on survivors. Cleaner architecture. |
| **P2** | **HTF Data Reuse (SCALP)** | 1h data fetched once and reused as HTF filter for 15m. Eliminates N+1 extra HTTP requests. |
| **P2** | **Retry + Exponential Backoff** | All Binance API calls auto-retry 3× with exponential backoff. |
| **P2** | **Reduced Workers (30→10)** | Respects Binance IP rate limits (~1200 weight/min). |
| **P3** | **Modular Architecture** | Split into 6 modules: `config`, `indicators`, `exchange`, `filters`, `scoring`, `telegram_bot`, `main`. |
| **P3** | **Logging (not print)** | Structured logs with timestamps + levels. No more silent `except: pass`. |
| **P3** | **Type Hints + Docstrings** | Every public function is typed and documented. |
| **P4** | **Better Telegram Command Handling** | `update_id` file persists across GitHub Actions restarts. No `boot_time` logic that skips valid commands. |

## 🛠 GitHub Actions Workflow Example

```yaml
name: Elite Scanner

on:
  schedule:
    - cron: '0 */4 * * *'   # every 4 hours
  workflow_dispatch:

jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install deps
        run: pip install -r requirements.txt

      - name: Run scanner
        env:
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          TELEGRAM_CHAT_ID:   ${{ secrets.TELEGRAM_CHAT_ID }}
        run: python run.py

      - name: Persist update_id & mode
        uses: actions/cache@v4
        with:
          path: |
            last_update_id.json
            mode.json
          key: elite-scanner-state-${{ github.run_id }}
          restore-keys: elite-scanner-state-
```
